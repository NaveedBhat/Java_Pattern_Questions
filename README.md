# Java Pattern Questions

A collection of Java programs focusing on various pattern printing exercises, logical problems, and fundamental programming challenges.

## Project Structure

The project is organized into several categories of Java files located in the `src` directory:

- **Basic Patterns (`Pattern_N_Question.java`):** Simple pattern programs (1-9) to understand loops and nested structures.
- **Advanced Patterns (`Advanced_Pattern_N_Question.java`):** Complex pattern logic (10-20) for deeper practice.
- **Exercises (`Exercise_1_Question_N.java`):** General programming exercises covering various logic-building scenarios.
- **Bug Testing (`BugTest.java`):** A utility file for testing and identifying common coding issues.

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher.
- An IDE like Android Studio, IntelliJ IDEA, or a simple text editor with a terminal.

### Running the Programs

To run any specific pattern or exercise, compile the file and run it using the command line:

```bash
# Navigate to the project root
cd /Users/naveedbhat/Personal_Projects/Java_Pattern_Questions

# Compile a file
javac src/Pattern_1_Question.java

# Run the compiled class
java -cp src Pattern_1_Question
```
